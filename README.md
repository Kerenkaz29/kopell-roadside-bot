# Kopell Roadside Bot

WhatsApp bot demo for roadside assistance dispatch (Coppel/Kopell Group interview demo).

## Stack
- Node.js + Express (webhook server)
- MongoDB (conversations, requests, technicians)
- WhatsApp Cloud API (Meta)

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and fill in values
3. `npm run dev`
